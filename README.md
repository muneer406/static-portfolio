## What it is

A single-page portfolio with a vintage, paper-and-ink treatment. Sections for home, about, skills, experiments, projects, testimonials and contact, with inline SVG icons defined once and referenced by id, so there are no icon font or image requests.

Three files, opened directly in a browser:

| File | |
|---|---|
| `index.html` | Every section, plus the inline SVG sprite |
| `styles.css` | Layout, type and the paper treatment |
| `script.js` | Navigation and scroll behaviour |
| `Assets/` | Portrait imagery and the map texture |

```bash
git clone https://github.com/muneer406/static-portfolio.git
cd static-portfolio
open index.html          # no install, no server, no bundler
```
